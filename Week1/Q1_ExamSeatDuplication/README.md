# Week 1 Assignment — Problem 1: The Exam Hall Seat Duplication Checker

Scans a list of assigned seat numbers and flags any duplicates before the exam starts.

**Constraint:** arrays and loops only — no Collections classes.

**Method signature:** `void checkDuplicateSeats(int[] seatNumbers)`

## Run
```bash
javac ExamSeatDuplicateChecker.java
java ExamSeatDuplicateChecker
```

## Sample output
```
Seat Numbers: {101, 102, 103, 102, 105}
Duplicate Seat Number Found: 102

Seat Numbers: {101, 102, 103, 104, 105}
No Duplicate Seats Found
```

**Concepts:** Arrays, nested loops, conditional logic, output formatting.
