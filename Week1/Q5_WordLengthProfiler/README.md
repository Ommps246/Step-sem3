# Week 1 Assignment — Problem 5: The Movie Review Word Length Profiler

Splits a review into words and classifies each as Short (1-4 letters),
Medium (5-8 letters) or Long (9+ letters), then prints the counts.

**Method signature:** `void classifyWordLengths(String review)`

## Run
```bash
javac MovieReviewWordLengthProfiler.java
java MovieReviewWordLengthProfiler
```

## Sample output
```
Review: "This movie was absolutely fantastic and thrilling"
Short: 3 | Medium: 1 | Long: 3
```

**Concepts:** String splitting (split()), loops, conditional logic, counting/categorization.
