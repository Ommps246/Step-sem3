# Day 1 — Problem 5: Reverse Customer Name

**Scenario:** The Customer Identity Verification System

Returns a reversed copy of a customer name while leaving the original untouched.

**Method signature:** `String reverseCustomerName(String customerName)`

## Run
```bash
javac ReverseCustomerName.java
java ReverseCustomerName
```

## Sample output
```
Original Name: Sunil
Reversed Name: linuS
Original after call (unchanged): Sunil
```

**Concepts:** String traversal, character array manipulation, string reconstruction.
